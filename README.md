## About

I'm **Hossam Gouda**, an agricultural engineer with **10+ years in irrigation systems, water infrastructure and agricultural projects**, based in **Jazan, Saudi Arabia**. By day I run a branch for an industrial piping and irrigation supplier, handling key accounts with EPC contractors and export sales. Outside that, I build software for the engineering work I know well: hydraulic design, irrigation scheduling, field measurement and crop monitoring.

Hydraulics are deterministic in what I build. AI is used for interpretation, documentation and workflow automation, not for the calculations.

- 💧 **Domain:** drip & sprinkler design, HDPE/PVC pipe networks, pump systems, fertigation, ET/Kc water budgeting
- 🛠️ **Building:** offline-first, bilingual (Arabic/English) engineering tools for GCC contractors and farms
- 🎓 **Education:** Executive MBA, Quantic School of Business & Technology (2026) · B.Sc. Agricultural Engineering, Cairo University
- 🤝 **Open to:** irrigation / water / piping sales leadership roles in the GCC, and AgTech product collaborations

## What I'm Building

> Most of these are in private repositories while in active development.

| Project | What it does | Core tech |
|---|---|---|
| **Saqia** | Hydraulic design web app for irrigation networks | React · TypeScript · map-based network computation |
| **SAQIA FieldView 3D** | 3D drip irrigation visualizer with a physics engine: Hazen-Williams losses, pump affinity curves, PC emitters, venturi fertigation with EC dilution, Joukowsky surge | Three.js · monotone bisection solver |
| **AquaField** | GPS field-area measurement PWA with an FAO-56 irrigation module | PWA · Capacitor · FAO-56 |
| **FieldLens** | Satellite crop monitoring (NDVI / NDMI) | Sentinel-2 · Copernicus Data Space |
| **Ruwā** | Sensor-free irrigation intelligence, Arabic-first for MENA | FAO-56 Penman-Monteith ET₀ engine |
| **ShipDeck** | Offline export-operations tool: commercial invoices and packing lists with live HDPE pipe weight calculations | Single-file HTML app · XLSX/PDF export |
| **AquaCAD** | Automated irrigation design and bid/takeoff (priced BOMs) for GCC EPC contractors | Deterministic hydraulics + LLM copilot |
